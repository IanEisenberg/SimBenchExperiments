Part II — Feedback Mechanism Architecture

Commercial behavioral simulation · closed-loop system for continuously improving predictions

Three Structural Bets
1
Task/Environment Enrichment — not routing dispatch

Part I's gain came from richer environmental framing, not the classifier machinery. Every prediction receives rich decision-environment description; the model conditions on context universally. Abstain-on-uncertainty is a separate coverage policy. The enrichment configuration is a learned, gated artifact.

2
Data Normalization Layer → canonical behavioral records

All inputs — surveys, transactions, experimental outcomes — normalized into single-choice behavioral records before entering the stack. The survey-to-behavioral bridge (sampling from population distributions, r ≈ 0.4–0.6) is one path. Enables Centaur training on heterogeneous sources from day one.

3
Centaur + task/environment encoding — primary experimental lever

Foundation model fine-tuned on behavioral outcome data (Binz et al. 2024 approach) with the hypothesis that task/environment-enriched inputs further improve predictions. Cross-domain transfer to e-commerce is empirical — tested, not assumed.

Five Required Areas
①
Compounding Memory

L1 raw store (append-only) → L2 prediction ledger (stamped before outcomes) → L3 segment posteriors (EMA-weighted) → L4 calibrator cache (versioned, gated)

②
Method Spectrum

Cold (n<100, ICL/RAG from L3) → Warm (n≥100, calibrated + Centaur) → Hot (n≥10k, Centaur + LoRA adapter) · gated volume-based escalation

③
Signal Types

Revealed behavior → calibration labels only · Stated preferences → cold-start prior only · Synthetic bridge → Centaur bootstrap only · boundaries are load-bearing

④
Generalization

Centaur weights shared cross-tenant · per-tenant L1–L4 data isolated · method validation compounds across engagements · raw data never pooled

⑤
Guardrails & Evaluation

5-step update gate: shadow eval (≥1k preds) → Blum-Hardt η lift test → reliability ceiling (finite-n hard cap) → PSI drift check → human sign-off for fine-tune ships · auto-rollback on TVD +2σ · 30-day version retention
