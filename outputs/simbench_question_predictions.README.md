# simbench_question_predictions.csv

One row per **SimBench question** (all 13,510: both source files × all eval buckets),
with the human distribution, our system's prediction, the paper-faithful baseline,
and the SimBench score for each — plus metadata for slicing/grouping.

- **Rows:** 13,510 (dev 6,151 · val 3,767 · test 3,592)
- **Generated by:** `outputs/build_question_predictions.py` (reproducible, reads
  only the on-disk LLM cache — **no API calls, no cost**, deterministic).
- **Model:** `google/gemini-3.1-flash-lite` · **Scoring:** SimBench Eq. 2,
  normalizers built on the full split.

## "Our system"

`our_*` columns are the **anti_flattening** strategy — our best system with
*per-question coverage over all of SimBench* (mean S ≈ 41). The project's headline
system (task-kind router + abstain-floor) scores essentially the same on held-out
TEST (S=40.7 vs anti_flattening's 39.7 here) but its per-item predictions were only
ever cached for a subset, so it can't be reproduced for every question for free.
If you need the exact router predictions everywhere, re-run it live (costs LLM spend).

## Validation

Reproduces the authoritative TEST numbers exactly: test faithful = 35.21
(pop 30.88 / grouped 39.19). `uniform_score` averages to 0.00 by construction —
the defining property of a correct Eq. 2 normalizer.

## Columns

**Identity & grouping**
| column | meaning |
|---|---|
| `question_id` | stable 12-char hash of (dataset, file, question_text, segment) |
| `dataset` | source survey/task (ESS, OpinionQA, Choices13k, MoralMachine, …) — the natural "task" grouping |
| `task_kind` | coarse kind mapped from `dataset`: opinion_survey · knowledge · risky_choice · moral_dilemma · personality_scale · other |
| `eval_bucket` | leave-family-out bucket: `dev` / `val` / `test` (seed 0, 0.5/0.25/0.25, unit=question; required-Qs pinned to test) |
| `simbench_file` | which SimBench file: `pop` (unconditioned) or `grouped` (segmented) |
| `is_population` | True = unconditioned full population; False = a demographic segment |
| `num_segment_vars` | number of conditioning variables (0 for population) |
| `segment_vars` | names of the conditioning variables (e.g. `age_group\|cntry`), `\|`-joined |
| `segment` | JSON of the segment's actual values, e.g. `{"cntry": "Finland"}` |
| `n_options` | number of answer options |
| `group_size` | number of human respondents behind the distribution |
| `required_question` | one of the 3 assignment-required Qs (trust_president / gay_rights / internet_use), else blank |
| `question_text` | full input template (prompt + lettered options) |
| `options` | JSON list of option labels |

**Distributions & scores** (distributions are JSON `{option: probability}`, summing to 1)
| column | meaning |
|---|---|
| `human_dist` | the empirical human answer distribution (ground truth) |
| `truth_entropy` | normalized Shannon entropy of `human_dist` ∈ [0,1] |
| `tvd_to_uniform` | TVD(human, uniform) — this item's distance from uniform (difficulty) |
| `normalizer_Z` | dataset-level Eq. 2 denominator = mean `tvd_to_uniform` over (file, dataset) |
| `uniform_score` | SimBench S of a uniform prediction (the benchmark's zero point) |
| `our_system` | constant: `anti_flattening` |
| `our_pred` / `our_score` | our prediction and its SimBench score |
| `faithful_pred` / `faithful_score` | SimBench paper-faithful baseline prediction and score |

**Score:** `S = 100 × (1 − TVD(pred, human) / Z)`. 0 = uniform baseline, 100 = perfect,
negative = worse than uniform.

## Example queries

```python
import pandas as pd
df = pd.read_csv("outputs/simbench_question_predictions.csv")

df.groupby("task_kind")[["our_score", "faithful_score"]].mean()           # by task
df[df.eval_bucket == "test"][["our_score", "faithful_score"]].mean()      # held-out only
df.groupby(["simbench_file", "dataset"]).our_score.mean()                 # per dataset
(df.our_score - df.faithful_score).describe()                            # our lift over baseline
```


## Interactive explorer

`outputs/simbench_explorer.html` — a self-contained, offline item-level explorer
built from this CSV (just double-click it; no server/internet). Filter by
task/dataset/bucket, sort best-first or by lift, scroll/step through every question
(arrow keys or Prev/Next), and for each one see the **Human / Ours / Faithful**
answer distributions overlaid (with a uniform reference) plus the question text,
metadata, and scores. Regenerate with `outputs/build_explorer.py`. Two tabs: **Questions** (the item-level explorer above) and **Task summaries** — a topline of split-avg / pooled / pop / grouped (Ours vs Faithful, per bucket), a mean-score-by-task overview, and per-task score-breakdown / score-histogram / answer-entropy plots.
